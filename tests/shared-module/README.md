## Bounded identity exception

Keep **`ios/Shared/AlarmActivity.swift` byte-for-byte unchanged**, compiled separately into the app and widget as before. Do not add it to TodayShared or compile a copy there. It defines `AlarmMeta`, its Kind, and Pause/Resume/StopAlarmIntent. The existing `#if canImport(AlarmKit)` guard remains.

The app currently schedules `AlarmAttributes<AlarmMeta>` (through `AlarmScheduler.Meta`); the widget uses its locally compiled `AlarmAttributes<AlarmMeta>` in ActivityConfiguration. Moving those declarations into TodayShared changes their defining Swift module, including AppIntent identity. Matching Codable field names cannot prove that previously scheduled AlarmKit alarms and existing Live Activities remain discoverable/renderable or that their action buttons resolve. This lane has no old-app/new-widget AlarmKit runtime proof, and intentionally claims none. Integration must retain this source membership exception. Removing the exception requires a separate authorized baseline alarm/Live Activity creation, candidate app/widget readback and button-dispatch test with compiled identity evidence.
