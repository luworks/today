## Bugs found and fixed (in #277)

1. **"make it 4pm" became a new reminder titled "it".** With FastLane's own preview open, a follow-up
   that also passes the one-off gate was written directly. Older than P4 (the one-off gate ran first
   before FastLane existed too). Ask now reads the message as an answer to the open preview before the
   one-off gate; a new request ("Remind me to call Mom at 5pm") is not a refinement and still goes direct.
2. **"整理逾期" was added as a reminder titled "整理逾期".** `OverdueTidy` and the routing only knew 过期;
   they now accept 逾期 too, and the one-off gate refuses any Tidy request (unit test
   `FastLaneTests.testATidyRequestIsNeverADirectReminder`).
3. **An alarm from "设一个明天早上6点的闹钟" was titled "设一个 的".** `CaptureParser.alarmLabel` now returns
   "Alarm" when only the request's own words are left.
4. The Luna account screen still said "GPT-6 Luna · Medium" (the deleted strict mode's effort); it now
   says "GPT-6 Luna" and shows today's AI requests (agent runs) instead of the old per-call quota.
