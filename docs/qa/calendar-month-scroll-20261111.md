# Calendar paging and navigation — Issues #380–383

## Reproduction and fixes

The clean worktree began at `79b8922bc06c29289dd31cc9389c1d5232b22aad` and was fetched/fast-forwarded to the owner's installed source `07348b71fed6e81192d42a9e548818d5300041c2` before editing. The owned iOS 27.2 Simulator reproduced the phone screenshot: January -> February 2027 settled with January 25–31 over February 1–7. This is Simulator reproduction, not a new phone test.

- **#380, Month overlap:** each page used the current viewport height while retaining its own 4/5/6-week contents. A 204-point February page therefore let January's 255-point contents extend 51 points into February. Committing another week count also changed all paging coordinates. Keep page stride/internal viewport at six scaled rows, constrain each month's content to its actual row count, and crop only the external presentation to the compact committed-month height. Top alignment, page containment and whole-stride target quantization prevent overlap and fractional resting offsets.
- **#381, Year entry:** Month January 2027 -> Year twice opened January 2007. Year's collection identity used relative offsets while its scroll binding/targets used absolute years. Initializing state alone was experimentally insufficient (header2027/grid2007). Use absolute year identities throughout and seed the incoming browsed year before first layout.
- **#382, Year header:** a viewport starting with July 2028 published 2029 and tab return restored January 2029. The scroll binding names an anchor, not the first partially visible section. Publish the minimum actually visible absolute year through target visibility, keeping navigation positioning separate.
- **#383, 2 Day flick:** one grid fling from February 28, 2027 settled on March 2. Use explicit one-column stride quantization instead of a multi-column view-aligned limit; the final legal first column leaves both columns visible.

`CalendarPaging` shares the pure target calculation. Adjacent-page limiting applies only to user tracking/interaction/deceleration. Initial positioning, resizing and explicit distant-date requests retain their full destinations. A large-type candidate exposed this distinction: AX reported February 2028 while the grid was blank, and its first flick landed March1998 near the range start. The final phase-aware behavior fixes that observed failure. No Now-line, folded-hour, calendar-service, source-data or write behavior was changed.
