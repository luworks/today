顶部的全天时间轴全部保留，右下的 Settled 也保留。要定的是时间轴和列表的关系。下面 4 版都用你截图里的数据（周六 11 月 21 日），按 16 Pro Max 的真实 pt 尺寸绘制。A、B、C 都去掉了随时间移动的框，列表改回 Morning / Afternoon / Evening 分隔（#401 之前的样子：标题 + 细线 + 淡色卡片，不折叠）。D 是对照组：保留现在的窗口和 Later，只去掉自动移动。

现在07:47

拖“现在”滑块 = 你一直看着屏幕，时间在走：看每一版屏幕上有什么在动。点“重新打开 Today” = 离开再回来：已做完、已结束的这时才收走。每部手机都能操作：点或拖时间轴、滚列表、点 Now、点 Later。截图外的几项（15:00 和 21:30 以后）用灰条示意。

推荐（排序）

  1. C · 时间轴当滚动条。列表回到大家熟悉的早中晚 + 正常滚动，什么都不藏；时间轴上的框换了意思：不再是“列表只显示这一段”，而是“你正看着这一段”。框只跟你的手走，时间流逝时一动不动。你喜欢的那条时间轴因此有了实际用处：看忙闲、点一下跳过去、拖一下快速翻。万一用下来觉得框多余，去掉框就是 A，代码不用返工。
  2. A · 静态总览：最简单，最符合“少即是多”；缺点是时间轴和列表之间看不出对应关系，滚到晚上时时间轴不告诉你在哪。
  3. B · 时段高亮：早中晚在时间轴和列表上用同一套说法，但底色每天还是会跳两次，而且晚上 6 小时挤成一块，分辨率太粗。
  4. D · 只听手的窗口：解决了“自己动”，但没解决“太复杂”：窗口外的项被藏进 Later，截图里 08:00–09:00 那三项就是这样“看不见”的。

三版共同的规则：不自动滚动；进入 Today 时列表从顶上开始（做完的、结束的都已收走，顶上本来就是过点未做 + 接下来）；做完或结束的项留在原位变淡，下次进入才收走；过点未做的项红色时间、留在它的时段里；44 pt 一行、无分隔线、北京时间第二行照旧；Settled 放在最底下一行的右边。
