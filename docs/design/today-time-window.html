列表规则

  1. 过点未做永远可见：今天时间已过、还没完成的提醒，不折叠、不进 Later、不受窗口影响，排在 Now 线之上。只有它们多到超过一屏时才需要滚动，这是唯一需要滚动的情况。
  2. 已完成、已结束不列出：已结束的事件、响过的闹钟、做完的提醒只留在时间轴上（淡色）。想看就把窗口拖回过去。
  3. 刚勾完的不马上消失：划线留在原位，下次进入 Today、回到前台或换天时才收走，列表不会在手下跳动。
  4. 窗口长度 = 一屏放得下的量：按实际行高（含动态字体和当前显示的安静行）计算，不是固定小时数。SE 上短，Pro Max 上长。
  5. Later 一定点名硬承诺：窗口外如果有事件或闹钟，Later 行写出第一件；其余的在时间轴上都有标记，没有藏起来没痕迹的承诺。
  6. 一行一项：时间 · 图标 · 标题（单行截断）· 尾标（事件时长或 now，重复提醒用 ↻）。列表名不再占第二行，详情点开看。重复提醒用次要色，一眼分出例行和要事。
  7. 其他日子：窗口从当天第一项开始，规则相同；过去的日子显示完成记录（DayHistory），不标红。

时间轴交互

  1. 拖动：在时间轴上横向拖，窗口起点 1:1 跟手；每跨过一项的开始时间给一次 detent，快拖时合并；松手吸附到最近的一项或 Now，给一次 settle。列表跟着换段，不做位移动画，只做 120 ms 淡入淡出。
  2. 点一下：窗口跳到点击位置最近的一项。
  3. Now 胶囊：窗口不在 Now 时出现在时间轴右上角，点它回来；底栏 Today 按钮也回到 Now。回到前台、隔天、重新进入 Today 时自动回 Now。
  4. Later 行：点一下等于把窗口拖到 Later 里的第一项。
  5. 手势归属：时间轴独占横向拖动；顶栏和底栏的横滑仍然切 Tab，周条仍然翻周，左边缘仍然开侧栏（时间轴两侧各留 16 pt）。
  6. 浏览安静：窗口在 Now 时不发触感；Reduce Motion 下去掉淡入淡出。VoiceOver 把时间轴作为可调控件：上下滑一次移到前一项或后一项，读出“显示 08:00 到 20:00，之后还有 2 项”。
